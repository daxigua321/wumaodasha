# 上海有色金属交易中心楼宇大屏

这是目标网页的完整本地项目，包含页面结构、样式、交互脚本、动画和全部图片资源。

## 启动

在 Windows 中双击 `启动本地预览.cmd`，浏览器会打开：

`http://127.0.0.1:8765/`

如果 8765 端口已被占用，请先关闭占用该端口的程序。

## 文件

- `index.html`：页面结构和 SVG 效果
- `styles.css`：布局、进场动画、扫描光和交互状态
- `app.js`：楼层切换、自动巡层、数字动画和 Canvas 背景
- `assets/`：站点图片及图标
- `RESOURCE-MANIFEST.md`：原始资源大小和 SHA-256 校验值
